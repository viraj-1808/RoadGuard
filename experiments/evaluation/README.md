# Evaluation Experiments

This directory contains evaluation results and reports.

## Purpose

- Record evaluation metrics for each trained model
- Document small-object evaluation results
- Document false-positive and false-negative analyses
- Store qualitative analysis results
- Record cross-domain generalization results
- Document recorded-video and live-camera evaluation results

## Required Metrics

See `docs/MODEL_EVALUATION.md` for the full list of required metrics:

- Precision, Recall, F1
- IoU
- mAP50, mAP75, mAP50-95
- Small-object analysis
- False-positive analysis
- False-negative analysis
- Qualitative analysis
- Cross-domain evaluation
- Runtime benchmarking
